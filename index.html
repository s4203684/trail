    ☁ GitHub Gist Sync

    Your data syncs automatically to a private GitHub Gist. Works across devices and survives browser resets.

    ⚠ "Private" Gists aren't fully private — anyone with the link/token can view them, so don't share your token.

    Get one at github.com/settings/tokens → Generate new token → tick gist only
    Connected
